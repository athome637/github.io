# Channel Kit — эмодзи для Telegram

Универсальный набор из 12 статичных реакций для канала.

## Файлы

| Папка | Назначение |
|-------|------------|
| `pack-100/` | **Готово к загрузке** — PNG 100×100, прозрачный фон |
| `pack-512/` | Те же иконки 512×512 (стикеры / референс) |
| `index.html` | Превью пака в браузере |
| `generate.py` | Скрипт пересборки PNG |

## Состав

1. `01-like` — лайк  
2. `02-heart` — сердце  
3. `03-fire` — огонь  
4. `04-check` — ок / да  
5. `05-cross` — нет  
6. `06-clap` — аплодисменты  
7. `07-think` — думаю  
8. `08-rocket` — запуск / рост  
9. `09-idea` — идея  
10. `10-lol` — смех  
11. `11-star` — избранное  
12. `12-pin` — важное  

## Загрузка в Telegram

1. Бот [@Stickers](https://t.me/Stickers) → `/newemojipack` → **Static**
2. Имя пака + short name (латиница, например `mychannel_kit_by_YourBot`)
3. Отправить PNG из `pack-100/`, к каждому привязать обычный эмодзи
4. `/publish`

Нужен **Telegram Premium**, чтобы создавать и использовать кастомные эмодзи.

## Пересборка

```bash
python3 emoji/generate.py
```

Требуется Pillow: `pip install Pillow`
